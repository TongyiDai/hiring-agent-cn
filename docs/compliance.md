# 中国大陆使用边界

本页解释项目如何把部分法律原则落实为产品约束，不构成法律意见。实际部署方应结合处理目的、招聘规模、数据来源、模型服务商、保存期限和组织制度进行正式法律与安全评估。

## 设计依据

- [《中华人民共和国个人信息保护法》](http://www.npc.gov.cn/npc/c2/c30834/202108/t20210820_313088.html)第二十四条：自动化决策应保持透明、公平、公正；对个人权益有重大影响的决定，个人有权要求说明并拒绝仅通过自动化决策作出决定。
- 同法第二十八至三十条：敏感个人信息需要特定目的、充分必要性、严格保护措施，并在相应情形下取得单独同意和额外告知。
- 同法第三十八条：向境外提供个人信息需满足相应法定条件。
- 同法第五十五条：处理敏感个人信息、利用个人信息进行自动化决策、委托处理或向境外提供等情形，应事前进行个人信息保护影响评估并记录。
- [《中华人民共和国就业促进法》](https://www.gov.cn/guoqing/2021-10/29/content_5647636.htm)第二十六条：用人单位和职业中介机构应提供平等就业机会和公平就业条件，不得实施就业歧视。
- [《网络招聘服务管理规定》](https://www.gov.cn/zhengce/2022-08/31/content_5711333.htm)第二十一条：网络招聘服务应遵守个人信息保护规定，建立用户信息保护制度。
- [《生成式人工智能服务管理暂行办法》](http://www.cac.gov.cn/2023-07/13/c_1690898327029107.htm)：涉及个人信息的训练数据处理和服务使用需要遵守个人信息保护等要求。

## 产品控制

| 原则 | 项目中的默认控制 | 部署方仍需完成 |
|---|---|---|
| 人工决策 | 无自动淘汰端点；岗位确认门；人工逐条签核 | 建立内部复核、申诉和说明流程 |
| 数据最小化 | 匹配前隔离身份与高风险属性 | 确定合法处理基础和最短留存周期 |
| 透明与可解释 | 每条判断引用证据 ID、原文和位置 | 向候选人提供适当告知和说明渠道 |
| 公平招聘 | JD 风险扫描；禁止属性不进入匹配 | 对岗位真实必要性和结果差异持续审查 |
| 本地优先 | 默认不启用外部模型或平台 API | 外部处理前核对委托、同意与数据流 |
| 跨境控制 | 默认模型地址是 `127.0.0.1` | 使用境外服务前完成适用程序和评估 |
| 审计 | 输入/JD 哈希、版本、人工变更记录 | 设置访问权限、保留期限和删除机制 |

## 建议的上线前检查

1. 明确系统是阅读辅助，还是会影响排序、进入面试或淘汰；影响越大，控制要求越高。
2. 完成个人信息保护影响评估，并记录处理目的、字段、接收方、期限和安全措施。
3. 确认候选人知道其材料将如何被处理，以及如何请求说明或人工复核。
4. 禁止招聘团队把性别、年龄、婚育、民族、宗教、户籍、无必要的健康信息放入匹配规则。
5. 对不同群体的误报、漏报和人工覆写进行周期性审查，但避免为了评估公平而额外收集不必要的敏感属性。
6. 外部模型和代码平台接口逐项审查数据流；未完成确认时保持关闭。
7. 为 Web 部署增加认证、最小权限、TLS、限流、恶意文件扫描、隔离执行、加密和删除计划。
8. 为候选人提供错误更正、解释和人工渠道。

## 禁止用途

- 仅凭本工具结果自动拒绝、自动录用或自动推进；
- 根据姓名、照片、性别、年龄、婚育、民族、宗教、户籍、籍贯、住址或无必要的健康信息匹配；
- 推断性格、忠诚度、离职风险、政治倾向、家庭状况或其他材料未明确提供的属性；
- 抓取候选人未主动提供的社交关系和私人账号；
- 将真实候选人材料放进公开 issue、测试、演示或不受控的模型服务。
